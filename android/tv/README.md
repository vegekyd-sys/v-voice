# V Voice Android TV

电视原生薄壳，已从独立本地仓库迁入 v-voice。原生壳迁入时为 0.3.11，原仓库代码提交 `1c3fcb4a7969fea06ad03819a2f6ea214e37c664`，迁入快照 `905dcb6`。

负责阵列麦克风桥、单 WebView 前台服务、跨应用浮层、遥控焦点及屏幕关闭清理。共享页面在 `../../lab/gpt-live-h5`，本地 fixture 为 `../../scripts/candidate/tv-island.mjs`。首页由独立 family-tv 仓库维护。

## 全屏通话候选 0.4.3

在家庭首页点 V 拨号，接通后按确定或选「全屏」。全屏使用网页通话页。有讲解内容时，画板自动出现在聊天旁边；收起画板后可从「看画面」重新打开。图片可打开查看，多页讲解用「上一页」「下一页」翻页。收起、返回或 Home 后可以打开其他应用，回到桌面再点头像可继续同一通话。放大图片或打开报告时，返回先关闭当前内容。

在仓库根目录运行下列命令可在本地复查。模拟麦克风开始送帧后，替身会提交月相问题、答复和配图。语音、模型与图片来源均在本机。

```sh
TV_FIXTURE_LESSON=1 TV_FIXTURE_RECOVERY=1 node scripts/candidate/tv-island.mjs
```

在另一个终端构建并用下方工具安装到 FamilyTV_UI，打开家庭首页的 V 头像即可体验。

## 本地构建

JDK 17/21、Android SDK 34：

```sh
./gradlew --no-daemon :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
python3 tools/local.py
```

默认包名 `live.tianyi.vvoice.tv.lab`，仅装命名模拟器。正式电视使用受控兼容构建与既有签名，不分发个人入口/签名。小米电视 MiTV-MFTR0 已安装同签名的 0.4.3-full-call-tv 候选壳。每次拨号重新授权阵列通道。正常挂断后释放麦克风、移除浮层，桌面显示时会提前加载绑定的共用网页和阵列处理模块。点击头像才申请本次采集令牌并拨号。两分钟复拨窗口结束后会释放通话服务，桌面仍可保留一张已准备的网页。息屏释放待机页，系统回收进程后，下次桌面通知重新准备。

## 真机复查

1. 在线上常驻网页选择豆包，从点击拨号分别计时到连接就绪、首段 PCM 到达、音频开始渲染。在电视分别测桌面首次加载后、桌面停留超过两分钟后、系统回收进程后的拨号以及短间隔复拨，从桌面点击计时。记录入口、设备、模型、样本数和截止事件。
2. 在独立候选通话中，将固定的中文语音按每帧 20 ms、24 kHz、单声道 PCM 送到电视的回声消除输出端。可用“请用画板给我讲解月相为什么会变化”。确认豆包转写命中主题，服务生成讲解，同时电视屏幕出现相符的画板、聊天和播放。只在专用测试窗口替换输入，结束后核对候选产物哈希并释放测试页面。模拟音频覆盖从上行到播报的链路，真人远场拾音和回声另测。
3. 普通聊天和画板播报各取一段。记录阵列采集帧数、队列丢帧和播放缓冲耗尽次数。录屏、连续抓取界面树会给电视增加负载，日常通话和压力测试分别记录。
4. 从桌面头像按确定，录像确认只放大一次。讲解中挂断，逐帧确认头像从画板旁回到桌面头像，中间连续可见。通话中按返回、打开系统设置、回首页再展开，确认会话代次一致。挂断后查麦克风和前台服务，再拨检查新会话。
