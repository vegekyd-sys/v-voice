# 真机安装与接受

必须使用带操作按钮的真实 iPhone，并记录设备型号、实际 iOS 版本、App build、网络、音频路由、是否锁屏／前台、重现步骤和实际听感。模拟器测试不能替代下表。

安装前：Xcode 登录有权限签名的 Apple Developer 团队；连接、解锁并信任手机，开启开发者模式。运行 `ios/scripts/build-device.sh` 完成开发签名、导出和安装。查看构建输出中的实际签名／安装结果，不把未签名 archive 改名 IPA 当作安装包。

首次真实连接需要用户本人绑定自己的完整入口。真实通话和模型使用按当次人类授权执行；测试前说明会使用哪个既有服务／模型，不能自动启动付费循环或改正式服务。
