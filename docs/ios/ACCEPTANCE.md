# 真机安装与接受

必须使用带操作按钮的真实 iPhone，并记录设备型号、实际 iOS 版本、App build、网络、音频路由、是否锁屏／前台、重现步骤和实际听感。模拟器测试不能替代下表。

安装前：Xcode 登录有权限签名的 Apple Developer 团队；连接、解锁并信任手机，开启开发者模式。运行 `ios/scripts/build-device.sh` 完成开发签名、导出和安装。查看构建输出中的实际签名／安装结果，不把未签名 archive 改名 IPA 当作安装包。

首次真实连接需要用户本人绑定自己的完整入口。真实通话和模型使用按当次人类授权执行；测试前说明会使用哪个既有服务／模型，不能自动启动付费循环或改正式服务。

## build 7 · 完整 Reaction

- build 6 仅同步 7 张首页／基础状态头像，没有完整 Reaction。build 7 已纠正该遗漏。
- 全 52 个 H5 图库条目和 15 个 reaction-* 条目均打入 App，自动测试逐一验证 UIImage 可加载及 continuation 引用有效。原生 23/23、既有 H5 Reaction 26/26；实际模拟器出现 reaction-0 → reaction-1 → listen-5 的批准序列，并产生对应 displayed 事件。
- 新用户语义可取消／淘汰旧响应；方案遮盖和后台不发送语义判断；判断失败不影响录音或工具。只有当前用户主动通话、头像实际可见时才按 H5 方式请求原判断接口。
