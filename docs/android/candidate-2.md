# Android Candidate 2 — 0.1.1 (2)

独立分支 `codex/voice-android`，PR #145。对照 iOS `H5CallView` 与设置面板的当前交互，继续复用服务端 H5。没有修改 iOS、Gateway、Worker、工具授权或共享配置；选择 Candidate 验证，无需占用共享 VLab。

## 本次调整

- 去掉顶部原生标题行，首页只保留右上角「设置」，通话中使用轻量图标；网页阅读器、更新日志和任务弹层出现时隐藏。
- 设置改为底部圆角面板，Public 固定第一，标记当前入口，支持仅移除本机绑定。移除当前入口前先准备 Public；准备失败时保留原绑定。
- 通话中可查看设置，但不能切换或移除入口。麦克风、通知授权状态与系统设置入口集中展示。
- Android 返回键优先收起键盘、更新日志、模型菜单、阅读器和文字输入；没有这些表层内容时才返回页面或将通话置于后台。
- 系统安全区和键盘避让统一由宿主处理；加载和页面错误居中显示。通话中的非致命错误仍保留继续／结束通话选项。

## 验证与交付

独立 Android 16 / API 36 模拟器，真实 H5 与本地模拟模型上游，不保存录音、不产生付费模型调用。

- 两项设备 instrumentation 测试通过：WebView 顶部与系统安全区直接相接、设置当前选择与通话锁定、更新日志／模型菜单／阅读器返回、键盘避让与两次返回。
- 同一回归还验证了合成播放队列排空、后台／关屏音频帧持续、通知静音／展开后挂断、麦克风释放、重拨超过旧清理定时器、子 frame 拒绝。
- 入口回归包含移除当前绑定回 Public、移除非当前绑定、禁止移除 Public、失效回退与凭证加密。
- 85 项 Node 测试通过（含 6 项 Android 桥测试）。Android 编译、Java 单元测试和 lint 结果见交付回执。
- 已在 Codex 内置浏览器检查真实模拟器首页、设置、阅读器与键盘截图。键盘动画稳定后输入框和通话按钮都在可视区域内。

包名 `com.versa.vvoice.candidate`，Android 11+，开发签名，可覆盖 Candidate 1。交付 APK 使用正式服务地址；测试用 loopback 地址不进入交付包。旧 APK 保留作为回滚基线。

首页日志文件已登记独立 Candidate 条目；未将它加入正式首页发布列表，正式发布时再启用。此次未合入、未部署服务、未提交 Google Play。
