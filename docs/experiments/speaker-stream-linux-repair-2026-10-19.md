# Linux 多人 Candidate 第二版修复记录

版本：`speaker-stream-linux.20261019.2`；仅独立候选，未合入、未发布线上。先处理确定的沉默路径，再根据第一轮真实接口结果修第二版。没有修改 Gateway 核心、线上服务、Nginx 或隧道。

## 历史记录的实际边界

用户报告两次真人试用出现漏回复、两人拆为四个 Speaker、重叠后不回复。检查发现候选构造时未接 `onAudit`/`audit`，systemd 只有启动日志；两个现有浏览器页面也已无临时 `speakerEvents`。私有 Gateway 仅能看到工具侧环境状态，无法重建被拦截的语音轮次。没有采集真人 PCM，因此不能复放这两通。下列原因是代码确认和新测试复现，不能冒充逐句还原真人通话。

Memory/Web 工具的环境失败不在本次修复范围。若工具已发起，不用无输出 watchdog 再重复发请求。

## 第一轮（de293e8）

- 修正预算在整个进程累计：改为每通独立300次 Decision/1800秒输入；最长30分钟，时长到达明确提示。
- 短句、未知声线、无字级时间的混合输入、判断失败有统一恢复路径；不把未确认人物硬分给已知人物。
- 同一个人物的原生连接仍在准备时等待同一个 Promise，减少取消、重连和整句重放。
- 接入有界的脱敏诊断：匿名编号、动作/置信度、长度、阶段、首音频与播放状态；不保存正文、名字、音频、向量或工具参数。
- 单测23/23、原有测试457/457。真实连续三次相同科普问题，首原生PCM在真实输入结束后3.136 / 2.465 / 2.612秒，无漏答。

第一轮自查发现：单纯 `conversation.item.create` 不会触发豆包开口，故该轮恢复尚不完整；旧判断还可能取消新话，短前缀仍可能新建多个声线，静默决策也有误判。第二轮据此修复，没有把第一轮测试通过当成完整验收。

## 第二轮

- 澄清改为显式原生 `speech_text_buffer.commit`：正常答案仍听原始音频生成，仅固定重说提示走原生播报。真实接口348ms收到首音频，字幕与提示一致。
- 每句放行音频喂完后12秒仍无音频或工具时，最多一次澄清；安静旁聊不触发此恢复。
- 迟到的 ASR/Decision 不取消新定稿问题。新声线需两个一致窗口，已入选片段不反复修订人物；高置信已知声线最多3个参考样本。
- 自动模式结合独立“是否向V说”的 typed 判定和安静概率，避免不确定静默吞掉清楚的问题；两者仍是同一个 Decision 请求，无新增串行模型调用。明确专注请求短确认，非目标声线的排他过滤保持生效。
- 真实合成多人链路8/8检查通过：两个不同人物、孩子问答对象、旁话静默、共同回应、专注切换、父亲过滤、孩子故事对象及实际原生音频。
- 真正两路PCM重叠的回归首次失败：提示轮流说后，父亲明确提问仍被 Decision 选 quiet；此失败已保留。改进静默判定后重跑通过：重叠结束1.802秒有原生澄清；随后普通问题3.616秒有原生答案，仍为两位人物。该次发生在补充独立 addressed 问题之前，后续补充的最终判定另有真实文本复验。
- 另一轮发现“V，你能帮我拿东西吗”被误当人际实物请求；加入独立 addressed 交叉检查后，包含此例、父亲重新加入、旁话和电视的14项文本 Decision 检查全部通过。

## 延迟口径

5.764秒是此前三次短样本的中位数，其中包含两次额外搜索，不能当固定的正常聊天延迟。此前稳定已知人物本来就约2.7秒；第一轮当前实测2.465–3.136秒，与用户体感更短一致。以上为真实输入音频结束至首原生PCM，不等于浏览器实际播放，也不是P95。

首次发现孩子/更新回答对象组合仍会更换人物会话并重放音频，本轮多人样本对应10.246 / 8.293秒，已知孩子故事3.281秒。仍有明显尾延迟，不能宣称所有轮次已经变快。首次/切换与普通轮次、工具调用应分别统计。

最终带 addressed 交叉判定的连续回归三问全部有音频：5.527 / 4.293 / 5.136秒，但分别触发 web_search/delegate_to_v，不能算纯直答。这三轮 Decision 为0.799 / 0.534 / 0.531秒，ASR末句定稿为0.501 / 0.495 / 0.453秒。不能拿第一轮2.6秒挑选性替代最终混合工具链结果。

最终产品浏览器合成输入实际播放在说完后3.331秒开始；ASR末句定稿0.609秒、Decision0.700秒，其余约2.02秒为原生输入/生成、传输及播放。Speaker A气泡与回答均可见，播放结束回到listening。该次普通直答没有工具调用。

最终专项单测32/32、原有测试457/457；真实文本Decision14/14。

## 证据与限制

合成测试收据和失败产物都在忽略的 `artifacts/speaker-native/linux-repair/` 及 Linux 私有目录；不提交真人内容。候选诊断目录0700、文件0600，每文件约4MiB，最多当前和前一文件。生产服务PID/启动时间在前后核对。

当前没有声源分离。两人真声、相似音色、远场/AEC、手机和长通话仍需真人复试；合成重叠恢复不代表可准确拆出每人的每个字。已分配片段4秒后不再持续检查人物切换，连续无停顿换人仍是限制。提高自动模式接话倾向的代价是可能更易插话，不能声称所有旁聊已解决。
