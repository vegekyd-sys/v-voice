## 问题与改动

1. 原 `createConversationCalls.begin` 只接受 group，DM 返回 null，导致私聊继续发送逐轮问答卡。显式 DM 会话入口改用同一状态/纪要流程；旧个人入口、身份权限与固定 session 不变。
2. 状态文字统一为「V正在电话通话 · 计时」，原卡更新为「V电话通话已结束 · 总时长」。
3. 图中 54 秒通话保存了 6 段、199 字文字，但摘要不可用。此前失败原因未被持久化：call.report-error 没有 voiceSessionId，且审计白名单不接受该事件。无法追溯断言旧请求具体失败码。
4. 相同记录按原配置重放耗时 33.610 秒，Grok 4.7 默认 high 推理产生 3399 reasoning tokens，接近 45 秒等待上限。新配置明确 low，仍保留 45 秒单次超时；超时、网络、429、5xx 或截断只重试一次（不重试鉴权/配置错误）。失败保留完整文字及安全错误码，审计支持挂断后的摘要失败。
5. 两份实际失败记录按新配置重放成功：11.043 秒 / 825 reasoning tokens，14.128 秒 / 1027 reasoning tokens；已人工对照原始文字，未把摘要重放当作新音频通话或新的手机验收。
