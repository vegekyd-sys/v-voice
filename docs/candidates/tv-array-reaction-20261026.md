# TV Reaction 与阵列收音候选

状态：本地开发、待具体版本验收。用户选择第 3 版，右侧按钮下方常驻 Reaction；不恢复顶部中央胶囊。

## 架构

首页只负责原生入口与遥控焦点。Android 薄壳只提供窗口、权限、前台生命周期和显式本体阵列输入能力。H5 保留唯一通话、模型、任务、工具、Reaction 和页面 owner；未复制到 Android。真实入口及身份映射保持已有服务端绑定，不提交链接。Web/iOS/机器人/音响普通路径没有启用 TV 阵列驱动。

- 首页 START_CALL 等共享页面可以拨号且有麦克风权限后，使用 owner/generation 与 bounded request ID 请求一次；重放、通话中重复入口不重拨。
- TV 默认豆包；不可用时明确报错，不暗中选 Grok。当前 TV array 能力只支持有实际 rendered PCM 的豆包/Grok，GPT WebRTC 不宣称支持该阵列路径。
- 本体采集使用 VOICE_RECOGNITION、48 kHz、4/6 indexed channels，显式 Built-In Mic；不假设第 0 路是人声，不回退 WebView 单声道。页面、权限或前台失效时停止；原始 PCM 仅内存流转，无录音文件/日志。
- 每个声道用独立的 WebRTC AEC3 实例，以播放器实际渲染样本作参考，再合成共享引擎所需 24 kHz 单声道。没有在 V 说话时静音用户麦克风。保留 BSD/Apache 通知和固定依赖完整性信息。
- 壳与 H5 必须配套升级；旧 8a70fe2 H5 不使用新桥。版本相同不能代替物理收音验收。

## 现场与证据边界

用户照片确有 V 自己的问候被识别为用户。只读现场显示 WebView 使用 CAMCORDER 单声道客户端，硬件提供 4/6 indexed 阵列；本体设备路由不是 RemoteSubmix。未发现可用预处理效果链。小爱同时使用阵列，两个客户端均未被系统 silenced。推断重点是阵列转单声道和回声路径；未测新驱动前不能宣称具体声道顺序或物理根因已完全证实。

合成测试：4 声道 ERLE 22.37 dB、重叠近端语音相关性 0.917；6 声道 ERLE 21.87 dB、相关性 0.925。初版多声道共享抑制器会误伤人声，已改为每路独立 AEC。当前通过只证明合成路径，不代表电视喇叭、房间混响、远场真人语音或真实模型打断通过。

实际 IAB Worker 与 bridge lifecycle 合成测试通过；原生模拟器验证一键拨号、豆包默认、实际测试音波、静音、同一通话展开/收起、挂断恢复小头像、再次拨号和 Home 释放。真实音频、物理遥控器、小爱、STR、付费模型均未在本次新候选验收。

本次不更新正式 Voice/Gateway，不改小爱、系统桌面、原有 ADB/STR 配置。后续安装仍须按家庭电视 AGENTS 对具体源码、APK 与兼容差异验收。
