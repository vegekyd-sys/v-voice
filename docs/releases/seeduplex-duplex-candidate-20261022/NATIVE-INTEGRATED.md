2026-10-22；本轮仅修改、重启自有 Candidate。未合入、未上线、未重启 Gateway 或正式 Voice。当前运行源码冻结为 `788d3073a59f977bfd8333fce6a1925982c79316`，版本 `voice-seeduplex-duplex.20261022.6`。

## 结论口径

这次用真实豆包 1.2.6.1、真实 Candidate 服务、HTTPS/WebSocket、实际浏览器麦克风上传和 AudioWorklet 播放做验证。输入为火山 `seed-tts-2.0` 合成的两人和电视声音，检测实际播放节点的波形，并录制该节点；没有使用真人麦克风或物理 iPhone。模型生成文字、网络清音、浏览器暂停与扬声器输出分别计量。

原生模式保留同一个连续音频会话和两人上下文；不再经过 Speaker / Decision 的整句放行。它仍不提供现有 Speaker 的稳定人物编号、人物气泡或授权身份。口头叫对姓名不能替代这些功能。

## 本轮开发

- 原生提示中明确当前来电者可有多人；按本人声音、自报姓名、喜好和计划绑定；同一人可连续说话，不能按轮流顺序猜人；不确定时澄清当前人的姓名。入口账号不等于此刻的说话人。
- 明确对 V 的请求与对旁人的称呼；电视台词中的“先停”不能自动代表对 V 的停声要求；静听时不评论背景、不生成静听说明。
- 针对原生模型输出的完整括号静听说明，短暂保留其文字及 PCM，再有界过滤；普通括号内容、混合正文和用户明确要求逐字朗读保留。过滤时不淘汰原回答，并按 response ID 恢复其未消费播放队列。没有启用全局括号删除，避免正常回答被吞。
- 现有流式 ASR 仅辅助停声，关闭人物分离；半句“等一下、先停”不能立即取消，直接叫 V 或明确针对当前播报的控制可较早触发。模糊短指令需完成并等待 400ms，后续继续说文件、停步等内容时撤销；延迟结果不能取消新回答。
- Candidate 的 `assisted` 播放策略保留可恢复的快速让话；主路音频持续上传。音量门槛只控制播放器暂让，不能作为人物、任务或权限判断。

这仍沿用原有一条停声 ASR，没有新增判人模型、Speaker 分离服务或 Decision 链路。ASR 会增加用量；纯 provider 模式另做对照后没有被选作当前默认。

## 最新实测

结果及严格局限由同目录聚合验收记录对应。每次干扰前须确认实际输出仍在发声；同一通话中的插话后姓名检查不另开模型会话。对音色与姓名做互换，以排除按男女或交替顺序猜人。

| 场景 | 实际播放节点结果 | 严格判定 |
| --- | --- | --- |
| 原提问者插话、改问 2+3 | 约 220ms 静音；改答 5；旧声音恢复样本为零 | 此样本通过 |
| 第二人叫 V 插话、改问 3+4 | 约 247ms 静音；改答 7；旧声音恢复样本为零 | 此样本通过 |
| 本人短句“等一下，先停” | 约 225ms 静音；旧声音未恢复；有停声确认 | 此样本通过 |
| 同一句插话、输入增益 55% | 约 3297ms 才静音；改答正确 | 停声不及时 |
| 另一音色的电视完整台词，含“先停”和“文件” | 没有清音或新回答；误暂停约 4154ms 后恢复原故事 | 抗干扰未通过 |
| 已介绍的第二人叫第一人拿杯子、别走 | 没有清音或新回答；误暂停约 7744ms 后恢复原故事 | 抗干扰未通过 |
| 电视音色只说“等一下，先停”，增益 40% | 没有暂停、清音或新回答；也没有可核验的原生转写 | 仅记现象，不能证明识别后成功判为背景 |
| 持续电视、台词与旁聊 | 起始干扰时确实正在播故事；约 4519ms 后出现未请求的新语音，整个背景序列两次替换播放 | 不通过 |
| 日常组，三通电话在插话后继续检查两人姓名与喜好 | 同一通话内连续检查合计 12/12 正确 | 此小样本通过 |
| 音色和姓名互换 | 完整姓名 3/4，另一次只答姓氏，严格不计；喜好 1/2，合计 4/6 | 绑定仍不稳定 |

正常音量两次改问的新回答首包分别在插话开始后约 7013ms / 8381ms，输入句长约 5450ms。220ms / 247ms 是旧声音停下的时间，**不是新问题得到回答的时间**。

最新冻结版共完成 9 通合成音频电话，均有服务端关闭记录，零工具调用、零 provider 连接错误；辅助停声控制触发 3 次，全部对应明确改问的真人测试素材。3 次静听说明被过滤，浏览器收到保留原回答的释放事件；电视和旁聊没有通过辅助 ASR 触发永久清音。另有两次拨号前置按钮 30 秒内不可用，未进入通话，保留失败记录后重试成功；原请求的 HTTP 状态未单独保留，不能把原因定为入口限频。

持续背景试验后半段有些刺激发生时播放器已暂停，不能单独声称这些刺激前原故事仍在播放；其失败由起始电视干扰前的有效播放和随后未请求的新语音确认。旁聊另有前置播放条件成立的独立通话验证。

本轮没有扩大相近女声验收；此前三档对照的整组错绑结果仍然有效。提示优化、正常组成功和口头姓名均不能证明已有可替代稳定 Speaker ID 的原生人物能力。

“没抢答、没取消”与“完全不暂停”是不同要求。背景导致可恢复暂停仍算体验缺口，不计为抗干扰全通过。数字是当前小样本单轮测量，不能当作延迟分位数或真人准确率。
