# 外部账号登录保持修复（Candidate）

版本：`voice-feishu-login-persistence.20261026.1`。尚未合入、部署或发布原生 App。

## 原因和修复

飞书入口每次打开都会先清除浏览器身份；外部账号的组织免登返回 20027 后又清除一次，因此昨天通过卡片确认的有效登录也被删掉。同时，拨号前确认模式隐藏了账号摘要和连接入口，用户只能看到 Public，无法从页面主动切换。

新卡片确认在服务端加密登录凭据中记录确认来源与会话。组织免登失败时，仅恢复同一浏览器仍持有的有效卡片凭据，并重新调用原有 Gateway 准入接口。成功的免登继续采用其实际返回身份。普通 OAuth 凭据不能作为免登失败的回退身份；显式重新连接、过期或准入失败均不能恢复旧身份。

首页保留当前使用方式与连接飞书身份按钮；Public 设置中可主动返回之前确认的账号会话。Public 本身仍为独立访客，不自动继承账号历史或权限。
