## 发布前验证

本次改动均属于 Voice 内部、既有 Gateway 接口与权限范围，选择隔离 Candidate，无共享 VLab 变更。

- Voice 1,023、speaker 95、fleet 11 项通过；生成 H5 与 iOS 壳一致性通过，PR 和合入提交 CI 均通过。
- 压缩目标回归实际注册 microphone/speaker AudioWorklet，并验证采样和 PCM 输出。旧代码压缩后可直接复现 `SyntaxError: Unexpected token '{'`。
- 右侧浏览器显示实际候选 UI，但其麦克风请求未完成。Chrome 仅本次授权后，实际打包页面接通本地 relay：持续输入帧、24,000 字节合成音频播放后队列归零、AudioContext running、无脚本错误，挂断恢复首页。
- GPT 原生候选已通过真实共享 HTTP 服务与两个本地 WebRTC peer 的合成 PCM、字幕、静音/恢复、owner 清理验证。此证据不等于上线后的真机 GPT 声音验收。
- 发布前 20:44 的真实飞书拨号在允许麦克风后因 worklet 语法错误失败，故没有有效的旧版接通耗时基线。

## 上线后真实飞书 benchmark

桌面飞书、同一现有内部账号、同一测试群、SeedDuplex 1.2.6.1。原始指标见 [benchmark.json](benchmark.json)；不提交会话身份、聊天正文、凭据或原始音频。

| 指标 | 第 1 次 | 第 2 次 | 第 3 次 |
| --- | ---: | ---: | ---: |
| 页面导航到身份确认且可拨号 | 3.370 s | 2.234 s | 3.862 s |
| 点击拨号到界面进入真实通话 | 5.165 s | 4.862 s | 4.677 s |
| 菜单点击到可拨号 | 无有效观察值 | 2.905 s | 4.651 s |
| 菜单点击到接通，立即点击拨号 | 无有效观察值 | 7.767 s | 9.328 s |
| 是否接通并正常结束 | 是 | 是 | 是 |

接通中位数 **4.862 s**。界面计时包含辅助功能轮询开销，不能当作精确首音时间。第一轮打开页面后工具间有观察停顿，所以其全路径计时剔除；后两轮自动连续完成打开、就绪、拨号和接通。第三轮发生在锁屏中断约 36 分钟之后，解锁后才继续，且接通后立即静音以检查安静播放。

上线前页面进入样本为 3.595 / 2.353 / 2.267 s。上线前是连续刷新，上线后包含从菜单重新打开及锁屏后恢复，缓存、飞书授权与网络条件不同；额外暖缓存对照没有形成有效样本，**不据此宣称整体提速百分比**。由于旧版拨号失败，也不计算接通提速比例。

三次通话均有真实模型输出，累计下发 105,502 / 421,056 / 105,552 字节音频；均观察到有音频后的空队列，客户端 underflow 均为 0。前两次记录到 541 / 708 个有效输入帧，第二次出现真实输入与模型回应；第三次立即静音，活跃输入帧为 0，符合该次操作。客户端统计与模型文字不代替物理听感验收，停顿诊断也不意味着长插话问题已修复。

共 3 次上线后成功模型通话、1 次上线前失败尝试；均已结束，没有残留通话/建连/后台交付。未保存原始音频；供应商结算费用当前不可得，不能报告为 $0。测试计划预算约 $5、总上限 $10，没有继续扩大模型测试。
