# 连接准备与音频启动组合发布

版本：`voice-connect-audio.20261027.1`。本记录先登记待发布范围；实际运行提交、两节点校验和上线后结果在部署完成后补齐。

## 范围与环境

- #169：飞书首页内联身份启动、请求内一次性核验复用、并行模型/打断连接、预约期间只读准备；不依赖平台 #499。
- GPT 修复 `4d89724`：共用 HTTP 响应保留已校验的 `webrtc` 传输，已安装 App 使用现有 GPT 驱动。
- 停顿诊断 `e7262a4` 的服务端部分：有界交付指标、播放状态、响应标识；不采集原始音频。其 Swift 长插话状态机未包含。
- 飞书真实拨号发现的网页音频启动错误：压缩后的匿名队列类不能直接作为 worklet 顶层声明，改成明确的局部变量绑定。

均属 Voice 内部、既有 Gateway 接口与权限范围，选择隔离 Candidate，无共享 VLab 变更、Gateway 重启、App binary 或固件更新。#161、#170 与长插话 Swift 候选仍待真机验收；底部新入口 #166 涉及平台/外部账号未验，不纳入；Android #145 最新候选未完成对应真机验收。

## 发布前证据

- Voice 1,023、speaker 95、fleet 11 项通过；生成 H5 与 iOS 壳一致性检查通过。
- 压缩目标回归实际注册 microphone/speaker AudioWorklet，确认采样和 PCM 输出；源码测试不能代替此检查。
- 真实桌面飞书、现有已登录账号、同一测试群：进入到可以拨号的页面单调计时为 **3595 / 2353 / 2267 ms**，中位数 **2353 ms**。首次与重复进入不分组，样本小；不代表手机或外部联系人首次登录。
- 20:44 的真实拨号在允许麦克风后失败，错误为 `Unexpected token '{'`，与生产 minified class 序列化复现相同。因此发布前没有有效的接通耗时基线，不能宣称接通提速百分比。
- 本地右侧浏览器可显示实际候选 UI，但收音授权未完成；不将该次等待算作音频通过。音频注册与数据处理由压缩产物回归覆盖，真实模型/飞书完整路径在发布后复验。

## 发布后必验

两节点同产物、ready、解除 hold、Gateway 身份及私有配置保留、HTTPS bundle/iOS revision 对齐、首页日志可见；从飞书打开电话、确认身份、拨号、接通与结束，记录页面计时和服务端事件。真实模型测试按本次授权开展短通话，控制在约 $5 预算、$10 总上限；实际账单若不可得明确未知，不把估算写作结算。
