# 拨号后更快接通

Tianyi 2026-11-12 授权合入和上线。发布后还没有真实通话。

## 变化

- 拨号时，Gateway 准入、工具目录读取、历史读取和豆包连接同时进行，之前是三段串行。提前读取只在准入返回同一会话和 Agent 时采用，否则丢弃。准入、每个请求的成员校验和一秒交接窗口不变。
- 问候在就绪那一刻播出，不再等页面收到就绪后多一个来回。
- 浏览器已授权麦克风时，取麦克风和拨号同时开始。GPT Live 的建会话同样并行。
- 阶段审计新增 `admitted` 和 `prefetch-failed`。并行时 `elapsedMs` 从收到拨号起算，包含准入。

## 部署

- PR #206 合入 main，`4d6835d` 于 2026-11-12 20:38 CST 用 `release:fleet` 发布到网页和设备两个节点，当时都空闲，没有延期。
- 两个节点的提交和文件校验值一致。Gateway 未重启，回滚版本 `0cd2679`。
- 原生 App 和固件没有变化。
