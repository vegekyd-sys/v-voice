# 手机接通、长句接续与任务连续性 · 2026-10-21

范围：Voice 自身的音频生命周期、ASR 就绪、电话语义接话、受保护请求与有界预听、接通欢迎语。沿用既有 Gateway 接口、工具身份和权限，选择独立 Candidate 验收；不涉及 Gateway/Worker 或共享配置迁移。

## 欢迎语修复

此前声学起声事件会在欢迎语准备完成前直接取消它，尚无正文或接话判断。现在手机场景保留欢迎语，新片段可独立预听；仅当最终语义接纳用户请求或告别时取消欢迎语。旁聊、不确定声音不能据此取消。确认的第一句话接续预听，不强制从头重放；挂断后晚到的准备结果不能再播欢迎语。家庭设备原先的起声规则保持不变。

## 已有真人候选验收

前版运行源码 c1839e6，物理 iPhone Safari 一通约 176.5 秒：7 个获准话轮、0 次整句回退；长问题结束到首段服务端音频约 3.1 秒，自然接话约 2.6 秒；3 次搜索均有工具交付及回答音频。实际听到还包含网络与播放时间，不能把服务端首音频当作物理扬声器延迟。

用户确认一处混合声线提示发生在实际开着电视的嘈杂房间，本轮不据此改动混合判定。插话后的新问题得到回答，但旧音频未及时清空，快速打断仍是已知限制；没有宣称本版解决开口即停。

## 本次验收与发布登记

欢迎语代码回归覆盖：准备期间背景起声仍问候、确认发言让位且不重放、电视旁白不取消、只播一次、挂断后不补播。主套件 654 项、Speaker 95 项通过。独立 Linux Candidate d1f4630 的公网真实模型合成音频验收通过：启动时输入 240 ms 噪声仍返回欢迎语，重复 greeting 仅问候一次；9.179 秒长问题零重放回退，结束到首音频 4.052 秒；后续查询通过预听接续，实际调用与交付各一次，首音频 2.973 秒。此处不是物理手机验收，正式回归结果在发布完成后补记。

发布必须先 PR 合入 main、确认合入检查通过，再从合入提交打包。正式服务切换前检查通话、创建、后台投递和媒体连接均为空，保存旧源码、原 unit/drop-in、私有环境与 Gateway 基线；只切 Voice，保留回滚。预听通过 Voice 私有环境显式启用 VOICE_STREAM_LOOKAHEAD=1，既有模型及身份保持原配置。
