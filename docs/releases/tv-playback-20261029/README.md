# 电视启动与连续回话输出修复

版本 `voice-tv-playback.20261029.3`。本轮针对用户反馈“首次使用启动很慢；V 回话一直卡顿”。沿用 2026-10-28 故障持续调试和 10-29 自行控制同一电视的授权；只更新独立 TV Voice 候选。正式 Voice/Gateway、小爱、桌面主题、STR 不在改动范围。

## 故障与修复

- 用户实际通话日志中，76 秒墙钟只推进约 47 秒 AudioContext 时间（0.624 倍）；旧的 queue-underflow 指标没有识别持续输出变慢。
- 同一真机的独立空白 WebView 重现，降低 UI 负担并不足以消除。改变 latencyHint、采样率、创建顺序的正常结果不能稳定重复，未交付这些参数修改。
- 交错重复 6 次 AudioBufferSource / 6 次 AudioWorklet：前者 0.961–1.009 倍；后者有一次 0.601 倍。新共享缓冲调度器再做 12 次冷 AudioContext 检查，全部 0.961–1.009，underrun 为 0。探针使用本地合成静音，不代表真人听感。
- 新调度器仅用于电视原生阵列且直接 PCM 输入的调用；其他输出仍用原有 worklet。按短时间窗调度 PCM，暂停收回尚未播放的样本、恢复从准确位置继续，clear 停止旧 epoch。模型与打断策略保留在共享 relay；输入 Worker/AEC 不变。
- 电视入口合并脚本，保留唯一 entry-startup 和服务端身份快照；提前加载版本化 AEC JS/WASM，并只缓存固定 DSP 资源。其他终端仍用原入口。打包前强制检查 bundle 与源码一致。
- 旧版原生冷启动探针为 8023ms。新版本真实模型结果将在安装回执中补充，不能用本地 fixture 的 855ms 作线上承诺。

## 本地验证

143 项共享回归通过，覆盖 PCM 时序、精确暂停恢复、epoch 清理、静音、调度掉帧诊断、TV host、输入/AEC、入口身份与 bundle。命名模拟器完整原生服务 + 共享 H5 fixture 通话：接通 855ms，15 个采样均为缓冲输出，时钟比 0.997–1.001，576000 字节合成输出，underrun=0；输入文字表单成功，挂断释放服务。内置浏览器完成拨号、文字输入、播放、挂断，无控制台错误。

## 安装边界

沿用语音壳 0.3.7、桌面 0.4.16。先确认候选无活跃通话/任务，再切换冻结产物；保留共享 `2e16ec3` 回滚。真机真实模型连续输出、首次启动、Home/应用切换结果由安装回执登记，真人远场/回声与实体遥控/STR 另验。没有采集或保存原始人声。

## 第一轮实机集成发现与后续修正

`9651773` 的实际模型测试已经使用缓冲输出，瞬时播放时钟约 1.0，但在测试展开全屏文字面板时出现 `TV_MIC_BACKPRESSURE`，不能记为通过；该轮接通 7620ms。资源表还显示旧模块的 modulepreload 与新 bundle 同时下载。后续删除 TV 专用 HTML 中旧模块预加载，只预加载入口 owner 和 bundle，并关闭软件绘制全屏头像的大范围动态模糊。完整真实模型结果继续在最终安装回执登记。

## 并行准备与后续定位

第二轮资源请求从 31 项降到 7 项，接通 6957ms，但展开文字并请求系统输入法仍出现收音积压。硬件绘制探针同样失败，不能把它归因为仅软件绘制。系统日志同时存在 Sogou TV 输入法连接失败；下一步分离输入法焦点与窗口展开。该问题的最终归因以安装回执为准。

第三版再合并独立 startup 模块（两个页面脚本共享同一启动 owner），避免其身份模块的额外网络串行请求；已授权 TV 阵列的本地 DSP 准备与远端模型连接并行，只有两者均就绪才开始真实采集。取消时释放迟到硬件与会话；相关并行/取消单测和浏览器慢连接取消验证通过。模拟器跨 Settings/Home 完整合成输出接通 824ms；仍不把该数当作真机启动时间。

## 最终实际模型验收

运行源码固定为 `33ea4953efdfaff76f4e1cd736c6458d44597402`，文件集 SHA-256 `c7ad25a60a7f540692e379a276c81dbb15e0cf157c95b28e66546db0170edab1`，版本 `voice-tv-playback.20261029.3`。两次真机新建 V 通话，合成语音触发实际 Seeduplex 连续回话；连接分别 5805ms / 4994ms（旧版 8023ms）。各观察 30 次、每次约 2 秒，均保持 connected，输出分别 3192054 / 3047708 bytes，其中 26 / 27 次有排队输出；时钟中位均 1.010、范围 0.936–1.014，underrun=0。期间 Settings/Home/重新展开保持同一通话，收音无错误、无原生暂停。固定文字注入历史的早期测试只有提示音，未计入连续回复验收。

最终候选无活跃通话或任务，电视回到家庭首页，产品 APK 哈希仍与 0.3.7 / 0.4.16 发布一致。完整回执位于相邻 `v-voice-tv-island/docs/releases/tv-playback-installed-20261029/`。原始人声未保存，真人听感、远场、回声与实体遥控/STR 尚未获得本轮用户验收。文字输入面板的输入法关联积压仍单独保留为未解决问题，不以本轮语音主路径通过覆盖。
