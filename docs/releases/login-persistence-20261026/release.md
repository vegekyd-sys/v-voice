# 外部账号登录保持与切换发布

版本 `voice-feishu-login-persistence.20261026.1`，用户已明确批准上线验收。运行 commit、双节点产物与上线时间在切换完成后登记。

修复重复打开飞书电话时删除已确认外部身份的问题，并恢复首页账号设置和身份连接；Public 提供显式返回原账号会话的入口。旧版未标记的登录记录需要重新确认一次，此后保留原有 30 天有效期，不因刷新续期。

## 验收依据

- Candidate 全套 963 项测试通过；内置浏览器以模拟账号走通登录、重开、Public 返回、切换账号和服务重启。原始证据见 [候选记录](../login-persistence-candidate-20261026/acceptance.md)。
- 生产 Gateway 只读探针使用一个已有真实动态账号，完成候选代码的卡片凭据生成、重开恢复、新实例恢复与原会话描述。共四次 `voice.feishu.resolve`、两次 `sessions.describe`，账号与会话一致、凭据未重签。见 [脱敏回执](read-only-admission.json)。卡片回调与飞书 API 为模拟，没有真实消息或模型通话，不能替代用户在真实飞书客户端验收。
- 共享 VLab 正被另一项未上线的平台改动占用。本次不改 Gateway、Worker、工具权限、身份准入协议或共享配置；采用 Voice 隔离候选与既有生产 Gateway 的只读接口验证，没有占用或改变共享平台。

## 发布边界

采用统一 fleet 发布入口，在空闲保护下更新 Web/iOS 与机器人/音响两个 Voice 服务节点；不重启 Gateway，不发布新 iOS 二进制或固件。保留两端原版本、服务启动参数、私有环境和回滚回执。
