# 电视阶段性正式发布

用户 2026-10-30 明确要求“正式做一次上线”，并指定电视原生壳并入 v-voice。

维护仓库收敛为 family-tv 首页与 v-voice 共享服务 + android/tv。原生源码从本地 v-voice-tv-island 905dcb6 迁入，产品代码为 1c3fcb4；已安装壳 0.3.11-host-focus-tv，首页 0.4.19-media-cue-tv（717c23d）。准确 APK 保留，本次不重装原生包。

## 变化

- 电视阵列采集通过有界消息通道交给共享 Worker，AEC/收音/播放仍由共享层处理。
- 修复电视输出时钟长期落后，使用仅电视阵列启用的缓冲播放；其他端保持现有音频执行路径。
- 首页即时放大和媒体拨号音，跨应用单一通话/头像连续变化；原生容器管理遥控焦点以消除整窗白框。
- 保留主线单连接拨号、首次输出观测、一个 V 的任务播报、来电身份与权限检查。
- 同一已授权目录的电视工具指导不改变 Gateway catalog/invoke 权限，使用既有接口，按本仓库规则采用隔离 Candidate；无 Gateway/Worker/会话协议修改。

## 已有验收

用户对准确首页 0.4.19 + 壳 0.3.11 确认“能听到，且没有白框”。原实机四通道收音、声音开关、Home/设置/内容页跨应用、同一通话恢复和挂断释放已有证据。此确认不扩大到真人远场、回声、所有实体遥控及 STR。

## 发布前验证

- 1095 项 Voice、95 项 speaker、11 项 fleet 检查全部通过，iOS 共用 H5 生成物一致。
- Android TV 迁入后单测/lint/release 构建通过；真实模拟器 SurfaceHandoff 仪器测试通过：加载期 WebView 不抢原生焦点，接通后确定键可挂断。失败重试、同 WebView 保持 14 秒、收起与关屏释放回归通过。family-tv 公开源码单测/lint/release 构建通过。
- 共享页面走本地 HTTP/WebSocket/真实 Android WebView；模型和数组输入为明确替身，不算真实音频验收。
- 首轮恢复脚本仍拦截旧 HTTP 预约，主线已走单连接拨号，故未注入故障；已将故障注入移到共同预约边界。第二轮发现历史已死亡辅助服务绑定使宽泛“nothing”断言失效，改为检查本次 CallService 已释放；不隐藏实际生命周期失败。

正式合入、双节点部署、电视入口迁移、准确哈希和后验结果在 release.json 中逐步登记，发布前状态不得视为完成。

## 回滚

共享服务按统一 fleet 原子空闲切换回到发布前 899ed2f；保留私有环境、启动参数、服务身份和持久数据。电视入口可恢复原候选，当前已验收 APK 不变。原本地仓库、冻结 APK 和此前 0.4.18/0.3.9 回滚暂保留；不清数据、不停小爱、不改主题/STR、不重启 Gateway。
