# 飞书旧入口与自动入口发布

本次修复历史群聊、私聊电话入口仍指向固定个人入口的问题。网页现在将已登记的旧链接重定向到同一会话的标准入口；平台为新群、新私聊自动生成标准入口，并将可识别的旧菜单原位迁移。群聊桌面入口在飞书侧栏打开，私聊使用飞书内置网页页签。来电者身份仍由当前飞书账号确认。

Voice 957 项主测试、95 项音响测试、11 项发布测试通过；PR 和 main CI 通过，iOS 随包页面与发布包精确校验通过。共享 VLab 的 19 项入口测试直接加载部署后的 npm 插件模块并通过，health RPC 正常。真实飞书接口只读检查覆盖测试机器人可见的 35 个群；写入被探针主动阻止，不能将此记录为已创建测试群菜单。

生产存量迁移已逐项读回：421 个群和 56 个私聊，共 477 个入口正确，其中 433 更新、42 创建、2 原本正确。另有 4 个私聊被飞书权限拒绝、1 个会话已解散；13 个历史用户缺少可恢复的 native chat ID。这些例外不计为已修复，也没有扩大可见范围或账号权限。

此前外部用户已在真实 iPhone 上确认「十二家」可以进入电话页。本次自动检查不代表真实音频、打断或全部来电者身份验收。没有自动拨号、付费模型测试、新 TestFlight 二进制或设备刷机。
