# 预听接续：减少整句重放等待

日期：2026-10-21。候选运行提交 `c1839e6e9b741431beb9c4385014e27bc39cc4a8`，版本 `voice-mobile-turn.20261021.5`。仅独立 Candidate 启用 `VOICE_STREAM_LOOKAHEAD=1`；默认关闭，未合入或发布正式服。

## 改动

之前保护获准回答时，新话轮不提前进入原生模型；等最终识别和接话判定完成，再以 1 倍速从句首重放，导致等待随句长增长。

现在在保护旧回答期间，可创建一个独立预听原生会话，按原速流式输入新话轮。旧回答与其工具保持工作，预听的音频、字幕、清除事件和工具调用先暂存。只有最终语义确认、人物处理方式兼容且预听通道仍有效，才切换当前会话并释放暂存输出；输入游标接着前进，不返回句首。

普通未知/成人使用相同的默认表达方式，确认成人不再无谓重建；儿童表达或回应对象不兼容仍走原先保守回退。旁聊丢弃预听，不能执行其工具。明确新请求和告别仍按已有主机判定执行。Gateway、Worker、工具权限与个人入口身份未改变。

每通最多一路预听，仅限电话场景；每分钟最多启动 8 次、每路最长 12 秒、暂存最多 1 MiB 或 600 个回调。过期、失败或超限只丢弃该路，保留旧回答；后续获准请求可回退。预听短暂增加原生会话用量，因此保持候选开关，不能据此自动开启正式服。

## 同代码、同音频开关对照

在同一候选代码中先关闭、后开启预听。每次同一通电话先短问答，再紧接两条长句。语音由本机 TTS 生成，经过真实公网候选、ASR、语义判定与小何原生模型；没有真人录音。

计时从最后一个输入 PCM 帧发出，到公网客户端收到第一段输出音频，包含识别、判定、原生模型及网络等待；不是物理手机扬声器的听感计时。

| 输入 | 预听关闭 | 预听开启 | 实际路径 |
| --- | --- | --- | --- |
| 2.067 秒短句预热 | 3129 ms | 3121 ms | 两次均无重放回退，基本不变。 |
| 9.179 秒长句 | 13163 ms | 3476 ms | 关闭时一次整句回退；开启时预听接续，零回退。 |
| 7.786 秒长句 | 11554 ms | 3327 ms | 关闭时一次整句回退；开启时预听接续，零回退。 |

两条长句均完整识别、收到与完整问题相符的回复；不是靠抢答前半句得到提速。样本只有两条长句，不能推出真实手机的稳定分位数或所有话轮均低于两秒。
