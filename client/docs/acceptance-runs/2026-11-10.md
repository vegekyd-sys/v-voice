## 这一轮发现并修好的

| 问题 | 怎么发现的 | 修法 |
|---|---|---|
| 判断「在底部」差 17 pt，回复时常不跟随到底 | UI 测试取滚动几何 | 公式补上顶部内边距 |
| 跟随底部被内容变高打断；快速上滑时又被拉回底部 | E2E 截图 + UI 测试超时 | 只由读者自己的滚动决定是否跟随 |
| 「回到最新」只有箭头 11×7 pt 能点 | UI 测试点不中 | 整个 44 pt 胶囊可点 |
| 长对话里一次跳不到底 | UI 测试截图 | 跳到确实到底为止 |
| 回车没发出：输入法提交和回车合并成一次更新 | UI 测试截图 | 看插入的内容而不是长度 |
| 硬件键盘回车无反应 | E2E | `onSubmit` 发送 |
| 快速打字丢字（输入框绑定每次重建） | E2E 打字 | 输入框用本地状态 |
| 草稿离开会话就丢 | 代码审查 | 按会话保存，重启后还在 |
| 断网直接「发送失败」，重发换新 id 可能重复 | 代码审查 | 发件箱：排队、重连自动发、同 id 重发，V 侧去重 |
| 视频不转码，18 MB 以上发不出 | 代码审查 | 960×540 H.264；分片上传带进度；上限 64 MB / 3 分钟 |
| 刚发的图/视频在 V 确认后要重新下载 | E2E | 本机副本保留一天，V 的路径映射回本机 |
| 本机视频没有封面 | E2E | 指明 MIME 类型 |
| 键盘弹出挡住最新消息 | UI 测试 | 跟随中则键盘出现时滚到底 |
| 表格第三列被挤出卡片 | E2E 截图 | 按实测宽度，超宽时等比收窄换行 |
| 发出的消息又出现一份（带 V 的备注） | E2E | 去掉备注再比对；合并历史时清掉 |
| App 私聊未连上时打开会读成转录，出现重复卡片 | E2E | 记住 App 私聊；合并时只留渠道自己的条目 |
| 读过的会话重启后显示 1 条未读 | E2E | 记录最后阅读时间；打开时告诉 V 已读 |
| 重启后完成的回合显示「正在处理」 | E2E | 缓存不存进行中的卡片 |
| 列表预览带页脚（Agent: … Model: …） | E2E | 预览去掉小字 |
| 离线时首页「连不上 V」说两遍；离线时 App 私聊变普通行 | E2E | 只说一次；记住 App 私聊 |
| 一直显示「正在连接 V」看不出原因 | Tianyi 10/31 反馈 | 两次失败后说原因（没联网 / Tailscale / 网络） |
| 过期的配对链接毫无反应 | E2E | 提示过期 |
| 每次启动「正在连接…」一闪，列表跳动 | E2E | 超过 3 秒才显示 |
| 附件条显示文件名（视频是一串 ID） | E2E | 图片显示缩略图，视频显示大小 |
