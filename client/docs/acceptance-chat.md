# V App 聊天体验验收

2026-11-09 CST 起。V App 本质上是一个聊天工具，这份清单定义「聊天好用」具体指什么，
以及每一项怎么验证。每一项都要有证据（自动测试结果、计时日志或真机录屏）才算通过，
只看「没报错」不算。

## 怎么验

| 代号 | 方式 | 说明 |
|---|---|---|
| **UI** | XCUITest（`VClientUITests`） | 跑在模拟器上，用 `FixtureTransport` 回放固定对话，确定可重复 |
| **E2E** | 模拟器连 VLab candidate Gateway（装 vapp 插件、真实模型回合） | 端到端，模拟器走公网入口同款的 wss |
| **计时** | App 内 `os_signpost` + 日志 `[vperf]`，测试从日志取数 | 数值门槛都用 p95，不用单次 |
| **真机** | Tianyi 的 iPhone 连生产 V | 只用于模拟器测不出的：手感、真实网络、emoji、相机 |

网络条件：E2E 计时按公网入口实测（Cloudflare → V，握手约 1.1 s）给门槛；
另跑一遍 Network Link Conditioner「3G」看降级是否得体（不卡死、有提示）。

## A. 速度

| # | 验收项 | 门槛 | 方式 |
|---|---|---|---|
| A1 | 冷启动到首页出现（有缓存） | ≤ 0.8 s | 计时 |
| A2 | 首页数据刷新完成（公网） | ≤ 3 s | E2E 计时 |
| A3 | 点进会话到看见消息（有缓存） | ≤ 0.3 s | UI 计时 |
| A4 | 点进会话到最新消息到齐（无缓存，公网） | ≤ 2 s | E2E 计时 |
| A5 | 点发送到气泡出现 | ≤ 0.1 s | UI 计时 |
| A6 | 点发送到「正在思考」卡出现 | ≤ 1.5 s（不含模型） | E2E 计时 |
| A7 | 流式改写一条 15000 字回复，每次更新主线程耗时 | p95 ≤ 16 ms | 计时 |
| A8 | 600 条历史里上下快速滚动 | 无掉帧卡顿（hitch ratio < 5 ms/s） | UI（`XCTOSSignpostMetric.scrollingAndDecelerationMetric`） |
| A9 | 键盘弹出/收起 | 跟手，最后一条消息不被挡 | UI + 真机 |

## B. 发消息

| # | 验收项 | 方式 |
|---|---|---|
| B1 | 中文输入法拼写中（marked text）不会被提前发出；回车行为一致 | UI |
| B2 | 多行输入，输入框最多长到约 6 行后内部滚动 | UI |
| B3 | 每个会话各自保留草稿，退出再进还在 | UI |
| B4 | 发送后输入框立即清空、焦点保留，可以连发 | UI |
| B5 | 同一条消息不会发两次（网络抖动重试用同一个 clientMessageId） | E2E（断网重连） |
| B6 | 断网时发送：气泡显示「未发送」，联网后自动补发或一点重发 | E2E |
| B7 | V 回复中再发一条：不丢，按插话进入当前回合或排在后面，界面讲清楚是哪种 | E2E |
| B8 | 引用回复：长按→引用，发出的消息带引用块，V 看得到被引用内容 | E2E |
| B9 | 粘贴图片/从其他 App 拖入图片可以发 | UI |

| # | 验收项 | 门槛 | 方式 |
|---|---|---|---|

| C4 | 视频超过上限：提示具体原因，不静默丢弃 | — | UI |
| C5 | 上传中可以取消；失败可以重试；不阻塞继续打字和发别的消息 | — | E2E |
| C6 | 拍照/录像直接发（不经过相册） | — | 真机 |
| C7 | V 发来的图片：缩略图先出，点开全屏可缩放、左右滑看同组 | 缩略图 ≤ 1 s（公网） | E2E |
| C8 | V 发来的视频：点开即播（边下边播），可拖动 | 首帧 ≤ 2 s（公网） | E2E |
| C9 | 图片/视频可保存到相册、可分享 | — | 真机 |
| C10 | 发出的图片/视频在历史里重新进入会话后还在（V 侧路径可取回） | — | E2E |

## D. 看回复

| # | 验收项 | 方式 |
|---|---|---|
| D1 | 一个回合一张卡，原地改写，不闪不跳；完成后只留答案和页脚 | E2E |
| D2 | 完整 Markdown：标题、列表、引用、表格（横向滚动）、代码块（等宽、可复制）、行内代码、粗斜体、删除线 | UI |
| D3 | 链接可点；V 机器上的文件路径在 App 内打开（.md 渲染、其他走 QuickLook） | E2E |
| D4 | 在底部时新内容自动跟随；往上翻时不被拽回底部，出现「回到最新」按钮 | UI |
| D5 | 长按：复制、引用、表情回应、选择文字 | UI |
| D6 | 提问卡点按钮或打字回答；审批卡批准/拒绝后原地变灰显示结果 | E2E |
| D7 | 停止按钮一点即停，卡片显示已停止，之后不再有更新 | E2E |
| D8 | emoji、中文标点、长英文单词换行正常 | 真机 |

## E. 稳定

| # | 验收项 | 方式 |
