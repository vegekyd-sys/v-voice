# 无注册、无校准的自动 Speaker Candidate

独立候选入口：<http://127.0.0.1:26319/>。代码位于 `codex/volc-speaker-modes` worktree；旧的 `lab/volc-speaker` / 26318 保留，不接入生产 Voice V、Gateway 或音箱。人物关联仅用于对话，不授予工具或账号权限。

## 行为

Seed ASR 2.0 的流式说话人标注 → 匿名会话声线 `speaker:0` / `speaker:1` → Doubao Seed 2.1 Lite 根据带 Speaker 的话语关联姓名、选择回应对象 → 小何 TTS。

- 无声纹注册请求、无预设姓名映射、无“下一句是谁”校准。真人与合成回放使用同一条应用链路，`synthetic` 不参与身份判断。
- 初次开口显示 Speaker A/B/C，姓名和角色保持未知，可以直接匿名聊天。首个 Speaker 是初始主要对象。
- 模型通过自我介绍、明确的人物介绍或上下文更新资料，并引用话语 ID 和原文。界面区分“对话告知”和“模型推测 / 可能是”；两者都不是声纹认证。猜测不能覆盖已告知姓名，明确纠正可以更新。十二这个名字不等于年龄。
- `adaptive`：所有 Speaker 的话语和会话状态交给模型，决定回应谁和主要对象。`group`：可以回应多人。`exclusive`：按已识别的声线 ID 在对话模型前过滤，改名不改变放行声线，首次进入该模式默认锁定首个开口者。
- “你先介绍自己”只建立对话背景，不能自动进入专注模式。模式变更和专注交接须引用明确指令；程序核验引用及明确切换用语，拒绝只有模型布尔标记的升级。专注切换清空原话历史，人物资料的引用也不再传给该模型，保留姓名、角色等状态。
- 对方尚未开口时可以在多人模式记录待交接人，等自然开口并关联后完成交接。严格专注状态不让陌生声线的内容进入模型，因此无法在该状态中直接识别一个从未听到的人；需要先恢复多人模式让对方开口。这不是注册或校准。
- ASR 修订说话人编号时清除相关语义身份和历史；若涉及当前目标则暂停会话，要求重新开始，避免旧姓名继续控制放行对象。

## 试用

1. 打开候选地址，可点“回放自动识人测试”，不启用麦克风。
2. 点“开始真人测试”即可自然聊天，可以先不说名字，也可以说“我是天意，是十二的爸爸”。
3. 另一位自然加入。没有明确自我介绍时，观察是否显示“可能是十二”；说“我叫十二”后观察关联依据。
4. 在多人模式说“现在只和十二聊天”，观察主要对象变为对应 Speaker、表达适合孩子、其余声线转为“未调用对话模型”。如果对方还没开口，可以说“等十二开口后只和十二聊天”。
5. 结束后释放麦克风；新会话重新匿名识别，不跨会话记忆声线。新会话清空页面原对话，防止不同通话的 Speaker 标签混淆。

## 验证与限制

2026-10-15：19 项本地逻辑测试及旧实验 7 项回归通过。真实 API 的 57.58 秒合成输入包含 8 次发言，返回声线序列 `0/1/0/1/0/0/2/1`，没有姓名预绑定。

真实应用协议验证：姓名来自音频转写，第二条声线先被推测为十二，自我介绍后改为对话告知；普通介绍保持多人模式，父亲明确要求后才转为只跟十二聊，原父亲声线和第三条声线被模型前过滤；最后的孩子提问获得实际 TTS。6 次对话调用、12,655 tokens，单次模型耗时约 2.5–4.9 秒，另有 ASR 确认及 TTS 延迟。回执 `artifacts/volc-speaker/auto/verification.json`；MP3 完整解码通过，24 kHz 单声道。

额外 6 次真实模型调用（文字输入，用于策略验证，不冒充音频验收）：无人物信息时两条声线都保持未知；不把尚未开口的十二关联到父亲；等十二自我介绍后落实待交接的专注请求；同声线可明确纠正姓名。回执 `model-edges.json`。

浏览器复测曾发现模型把普通介绍误判成专注请求，已增加引用核验、明确切换用语检查和相应回归。姓名、角色及切换意图的语义判断仍有模型误判可能，当前校验用语以中文试用场景为主。

最终内置浏览器复测（684 px 宽，实际右侧面板）：从初始匿名状态点击回放，出现 3 个 Speaker；“可能是十二”经自我介绍变为“对话告知”；普通介绍不切模式，明确交接后才专注到 Speaker B。页面展示 6 条模型回复、2 条过滤，错误卡片为 0；播放器拿到 9.48 秒音频并加载完成（readyState=4）。页面 URL/标题、非空、无框架错误遮罩、应用控制台、截图及交互检查通过，无水平溢出。未验证独立桌面宽屏或真实手机。自动化工具自身偶有 Statsig 遥测请求失败，不属于本应用。回放结束后已释放会话，页面恢复为可开始真人测试的默认状态。

以上为合成音色和真实供应商 API 验证，不代表天意与十二的真实声线已经验收。尚待真人测试：短句/相似声线稳定性、麦克风采集、扬声器回声、自然打断、连续交流。只支持本次会话中的声线关联，不保证跨会话认出同一个人。

**尚不支持重叠语音的波形分离。** 严格模式过滤的是 ASR 的带声线转写；混在一条 ASR 结果里的旁人内容仍可能漏入，全部原始输入仍送火山 ASR。不能把本候选当成已通过的多人同时说话过滤器。

真人原始音频不落盘。日志仅展示于本次页面；开发验证回执只含合成素材。服务只监听回环地址；单会话 3 分钟、每进程最多 60 次对话调用、10 分钟输入及 6000 字 TTS。测试沿用约 5 美元单轮、总额不超 10 美元的实验预算，实际费用以供应商账单为准。

## 复现

从 worktree 根目录运行。沿用旧实验的忽略目录 `artifacts/volc-speaker/ark-endpoint.json` 和服务端凭据环境，不创建新声纹或生产资源。API 密钥与 Ark 临时 token 不进入浏览器。

```sh
npm run test:volc-speaker-auto
npm run test:volc-speaker
# VOLC_SPEAKER_ENV_FILE 指向现有私有配置文件
node lab/volc-speaker-auto/generate-fixtures.mjs
npm run lab:volc-speaker-auto
# 先结束页面的会话；端到端真实音频/API 验证：
node lab/volc-speaker-auto/verify.mjs
# 独立的真实模型策略验证（文字输入）：
node lab/volc-speaker-auto/verify-model.mjs
```

候选 launchd 标签：`com.versa.v-voice.volc-speaker-auto-candidate`；服务日志在 `/tmp/v-voice-volc-speaker-auto-26319.log`。不操作旧实验的 launchd 标签。验证通过不等于合入、发布或真人验收。
